Fluxo do sistema

Uma visao objetiva do que cada perfil executa durante o dia.

  1. Paciente e cadastrado pelo atendente ou administrador.
  2. Administrador gerencia a base de medicos.
  3. Consultas sao agendadas com validacao de horario.
  4. Administrador confirma ou cancela conforme a agenda.
